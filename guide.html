使い方ガイド

測色計で測った色を、デザインデータで使える数値にするまでの流れと、よくある質問をまとめました。分からない用語は、ツール内の ボタンでいつでも確認できます（このページのボタンも押せます）。

3ステップで使う

1

測って、CxF3で書き出す

分光測色計（i1Pro、eXact など）で色を測定し、付属ソフトから CxF3 形式で保存します。書き出し方法は下の説明へ。

2

ドロップする

変換ツールのドロップ欄に CxF ファイルを入れると、色見本と Lab・XYZ・sRGB・CMYK が即座に並びます。複数ファイルOK。

3

数値を使う

HEX はクリックでコピー。色見本をクリックすると全画面で色を確認できます。全データは CSV で一括ダウンロードできます。

ヒントはじめての方は、変換ツールの「サンプルCxFで試す」を押すと、デモ用の7色でひと通りの機能を体験できます。

CxFファイルの書き出し方

CxF は測色データの国際標準ファイル（ISO 17972）です。お使いの測定環境ごとの書き出し方の例です。

X-Rite i1Profiler（i1Pro 2 / i1Pro 3）

  1. i1Profiler の「チャート測定」でチャートを定義し、測定を実行します。
  2. 測定完了後、ページデータの「保存」ボタンをクリックします。
  3. 保存形式で CxF3（.cxf / .cmxf）を選んで保存すれば完了です。

その他の対応環境

  • X-Rite eXact / Ci シリーズ — 本体または DataCatcher 等の付属ツールから CxF3 で書き出せます。
  • TECHKON SpectroDens、コニカミノルタ MYIRO-1 など — CxF 出力に対応した測色計・ソフトの書き出しも読み込めます。
注意読み込めるのは CxF バージョン3（CxF3 / ISO 17972）です。古い CxF1・CxF2 のファイルはエラーになりますので、お使いのソフトで CxF3 として書き出し直してください。

ICCプロファイルでCMYKを正確にする

CMYK は印刷条件によって適切な値が変わります。ICC プロファイル をドロップ欄に入れると、その条件での正確な値になります。

  1. プロファイルを用意する — 日本の枚葉オフセット印刷なら Japan Color 2011 Coated（Japan Color 認証制度サイトからライセンス同意のうえダウンロード）。Photoshop 等をお使いなら、PCに Japan Color 2001 Coated.icc が既に入っています。
  2. ドロップする — CMYK 用プロファイル（.icc / .icm）をツール右側の欄へ。バッジがプロファイル名に変われば適用済みです。一度読み込むとお使いの端末に保存され、次回から自動で適用されます。
  3. 設定を選ぶ — 単色の色合わせなら「相対比色」＋「BPC ON」がおすすめ（Photoshop の初期設定と同じ組み合わせです）。

計算方法と精度

反射率スペクトルは 380–730nm / 10nm（36点）グリッドへ線形補間したうえで、CIE 1931 2°等色関数と標準イルミナント（colour-science 由来の正確なテーブル）で XYZ に積分し、L*a*b* へ変換します。白色点は「完全な白がぴったり L*=100, a*=b*=0 になる」テーブル自己整合値（CIE 15 の慣行）です。

sRGB は Lab(D50) から Bradford 変換で D65 へ順応後、IEC 61966-2-1 の行列で算出します。ICC 経由の CMYK 変換には jsColorEngine（業界標準エンジン lcms2 と ΔE≤0.06 の一致精度）を使用しています。実装は X-Rite i1Profiler の実測ファイルと lcms2 系リファレンス値による27件のユニットテストで検証済みです。

よくある質問

CxFファイルとは何ですか？ どうやって用意しますか？

測った色のデータ（分光反射率など）を機器やソフトの間でやり取りするための国際標準ファイルです（ISO 17972）。X-Rite の i1Pro・eXact などの分光測色計と付属ソフトで色を測定し、CxF3 形式で保存すると作れます。上の「CxFファイルの書き出し方」も参考にしてください。

ファイルが読み込めません。対応している形式は？

対応しているのは CxF バージョン3（CxF3）です。拡張子は .cxf / .cmxf / .mxf / .xml のいずれでも中身が CxF3 なら読み込めます。古い CxF1・CxF2 は構造が異なるため非対応です。その場合はエラーメッセージが出ますので、お使いのソフトで CxF3 として書き出し直してください。また、スペクトルも Lab 等の色数値も入っていないファイルは変換できません。

測定データは外部に送信されますか？

いいえ。ファイルの解析も色計算も、すべてお使いのブラウザの中だけで行われ、サーバーには一切送信されません。社外秘のブランドカラーや未発表製品の測定値でも安心して使えます。ページを一度読み込めば、機内モードでも動作します。

M0 / M1 / M2 のどれを見ればいいですか？

測定時に当てる光の条件の違いです（ISO 13655）。印刷物の評価・入稿基準には M1（蛍光増白剤の効果を含む業界標準）、過去の測定データとの比較には M0、増白剤の影響を除いて素の色を見たいときは M2 が使われます。迷ったら、取引先や社内の運用ルールに合わせるのが確実です。

画面に表示される色は、実物と同じ色ですか？

「できるだけ近い色」です。表示はお使いのモニタの性能とキャリブレーション状態に依存し、モニタで出せない鮮やかな色（sRGB域外）は一番近い色に丸めて表示しています（その場合は色見本に「sRGB域外」と表示されます）。一方、L*a*b* などの数値は測定データから正確に計算した値なので、色指定や検査にはこちらを使ってください。

CMYK値が Photoshop での変換結果と少し違います。なぜですか？

CMYK 変換はプロファイル・インテント・BPC の3つの設定で結果が変わります。Photoshop と比べる場合は、同じ ICC プロファイルをドロップし、「相対比色 + BPC ON」（Photoshop の初期設定）に合わせてください。これで実用上一致するはずです。なお、ICC を入れていないときの「簡易・参考値」は数式による当たり付け用の値で、印刷入稿には使えません。

Japan Color の ICC プロファイルはどこで入手できますか？

Japan Color 2011 は Japan Color 認証制度の公式サイトから、ライセンス契約に同意のうえ無償でダウンロードできます（配布条件があるため本ツールには同梱していません）。また、Adobe 製品をお使いの場合は Japan Color 2001 Coated.icc が既に PC にインストールされています（Windows: C:\Windows\System32\spool\drivers\color、Mac: /Library/Application Support/Adobe/Color/Profiles/Recommended）。

Pantone や DIC の色番号に変換できますか？

現在は対応していません。Pantone・DIC の色ライブラリは各社の権利物で、データを本ツールに同梱できないためです。今後、お手元にあるライブラリファイルを読み込んで ΔE が最小の色を検索する方式で対応する予定です。それまでは、本ツールで得た L*a*b* 値を Illustrator や各社ツールの色検索に入力する方法をおすすめします。

測色器メーカー純正ソフトの表示値と、小数点以下がわずかに違います

正常な範囲です。ソフトによって計算に使う波長間隔（10nm か 5nm/1nm か）や白色点の定義が少しずつ異なり、その差は多くの場合 ΔE2000 で 0.1 以下 — 人の目では絶対に区別できないレベルです。本ツールの計算方法は上の「計算方法と精度」に公開しています。

スマホやタブレットでも使えますか？

使えます。レイアウトはスマホ画面にも対応しており、クラウドストレージやメール添付から CxF ファイルを端末に保存し、ファイル選択から読み込めます。ただし色の見た目の確認は、キャリブレーションされた PC モニタで行うことをおすすめします。
