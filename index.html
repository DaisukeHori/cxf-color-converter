計算方法と精度について

反射率スペクトルは 380–730nm / 10nm（36点）グリッドへ線形補間したうえで、CIE 1931 2°等色関数と標準イルミナント SPD（colour-science 由来の正確なテーブル）で三刺激値 XYZ に積分し、CIELAB へ変換します。白色点はテーブル自己整合値（完全拡散反射面が L*=100, a*=b*=0 になる定義）です。sRGB は Lab(D50) から Bradford 変換で D65 へ順応後、IEC 61966-2-1 行列で算出します。

CMYK: ICC プロファイル読み込み時は jsColorEngine（MPL-2.0、lcms2 と ΔE≤0.06 の一致精度）で Lab→CMYK 変換します（PCS の仕様上、常に D50 の Lab を入力します）。未読み込み時の簡易CMYKは sRGB からの数式変換による参考値で、印刷入稿には使えません。Japan Color 2011 の ICC プロファイルは Japan Color 認証制度サイトからライセンス同意のうえ入手できます（本ツールには同梱していません）。

CxF1 / CxF2 形式には未対応です。Pantone / DIC など特色ライブラリへの近似検索は、ライセンス上の理由からデータを同梱せず、今後「手元のライブラリファイル読み込み方式」で対応予定です。
